# 基于预训练模型的人脸识别 Demo

> 人工智能视觉课程大作业 · **选题二：基于预训练模型的人脸识别 Demo**
>
> 技术路线：**MTCNN 检测与对齐 → 预训练骨干提特征 → 余弦相似度比对 → 阈值判定（含陌生人拒识）→ Streamlit 界面**

项目地址：<https://gitee.com/muyu1213/face_demo>

---

## 亮点速览

- **端到端可跑**：双击 `start.bat` 从零建环境到打开网页，5 个模块 863 行，依赖仅 7 个、不含 OpenCV（对齐用 NumPy + PIL 手写）
- **Demo 级真实数据验证**：7 张真人照片实测，正常尺度人脸 0.69–0.73 命中，陌生人 0.26–0.49 全部正确拒识（样本小，验证的是流程而非精度）
- **敢写负结果**：5 点人脸对齐实现正确，但实测无提升（0.761 vs 旧裁剪 0.790），如实记入文档而不是包装成「优化」
- **工程可靠性**：pickle 原子写盘 + `.bak` 备份、改名/删除失败可回滚、关键点退化有兜底，坏图不会让界面崩

## 三、安装与启动

### 方式 A：双击 `start.bat`（推荐，唯一入口）

它自动判断环境并按 4 步走（窗口显示 `[1/4]`~`[4/4]`）：

| 步骤 | 做什么 | 首次耗时 |
| --- | --- | --- |
| `[1/4]` | 找可用的 `uv` / Python（3.12 → 3.11 → 3.10 依次尝试） | 秒 |
| `[2/4]` | 建虚拟环境 `.venv`；已存在则体检，坏了自动重建 | 秒 |
| `[3/4]` | 装 `requirements.txt`（清华镜像优先，失败回退官方源；依赖齐全时走快通道） | 5~20 分钟 |
| `[4/4]` | 启动 Streamlit 并打开 <http://localhost:8501> | 秒 |

- 结束后**这个黑窗口不要关**，它就是服务器；关窗口或 `Ctrl+C` 即停止。
- 模型权重由程序首次用到时自动下载，**没有单独的预下载步骤**。
- 可选参数：`start.bat --setup`（强制重查依赖）、`--no-browser`（不自动开浏览器）、`--dry-run`（只看会做什么）。
- 常见故障：`'uv' 不是内部或外部命令` → 装 uv 后**重开命令行**；`error: externally-managed-environment` → 别加 `--break-system-packages`，用 `uv venv` + `uv pip install`；端口 8501 被占用 → `python -m streamlit run app.py --server.port 8502`。

### 方式 B：手动（macOS / Linux 或不想用 .bat）

```bash
python -m venv .venv
.venv\Scripts\activate                       # Windows；macOS/Linux 用 source .venv/bin/activate
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m streamlit run app.py
```

镜像源备选：清华 `https://pypi.tuna.tsinghua.edu.cn/simple`（默认）｜阿里云 `https://mirrors.aliyun.com/pypi/simple`｜中科大 `https://mirrors.ustc.edu.cn/pypi/simple`

## 四、使用流程

1. **人员注册** —— 填姓名 → 上传同一人的 ≥5 张不同角度照片 → 点「提取特征并注册」。不足 5 张会拦下并提示。
2. **人脸识别** —— 上传一张图片，自动检测并比对；绿框=已识别、红框=陌生人，下方显示姓名与相似度。
3. **人脸库管理** —— 查看人数/特征数/维度/文件大小，删除或重命名指定人员，下载 `face_db.pkl`，查看类内/类间相似度与建议阈值。
4. **原理与说明** —— 答辩速查页，一屏讲清流程、阈值取值与双骨干差异。

侧边栏可调参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 特征提取骨干网络 | `inception_resnet_v1` | 换成 `resnet18` 必须**重新注册**（特征空间不通用） |
| 运行设备 | `auto` | 有显卡自动用显卡 |
| 相似度阈值 | `0.6` | 调高更严格（本人可能被拒），调低更宽松（可能误认） |
| 展示 Top-K 候选 | `5` | 识别页候选人数 |
| 汇总方式 / mean_topk 的 N | `max` / `3` | 同一人多张注册图取最大分或 Top-N 平均 |
| 最小人脸尺寸 / 裁剪边距 | `40px` / `20px` | 漏检就调小最小尺寸 |

## 六、实测效果与已知边界

> 测试环境：CPU 推理｜骨干 `inception_resnet_v1`（VGGFace2）｜相似度阈值 `0.6`｜人脸库 2 人 / 15 条特征 / 512 维
> 测试时间：2026-11-25｜测试素材：未裁剪的真实照片（证件照、自拍、合照、全身照）

> **关于定位**：本项目是**课程 Demo**，不是生产系统。下面的数字用来证明「整条流程跑得通、阈值能区分本人和陌生人」，样本只有 2 个人、15 条特征，**不构成基准评测（benchmark）**，也不代表在更大规模人脸库上的精度。Demo 的价值在于流程完整、可解释、可复现。

### 6.1 识别效果

| 场景 | 人脸框尺寸 | 相似度 | 判定 |
| --- | --- | --- | --- |
| 证件照 | 303×410 | 0.709 | ✅ 识别为本人 |
| 半身自拍（户外） | 173×243 | 0.731 | ✅ 识别为本人 |
| 近景自拍 | 335×441 | 0.701 | ✅ 识别为本人 |
| 近景自拍（室内走廊） | 364×493 | 0.694 | ✅ 识别为本人 |
| 双人合照（本人） | 83×97 | 0.715 | ✅ 识别为本人 |
| 学士服全身照 | 57×70 | 0.548 | ❌ 判为陌生人 |
| 双人合照（同行者） | 88×103 | 0.526 | ❌ 判为陌生人 |

**规律很清晰：人脸框 ≥ 170px 时相似度稳定在 0.69–0.73；掉到 90px 以下就滑到 0.52–0.55，会被 0.6 阈值拒掉。**

### 6.2 陌生人拒识

用「留一法」验证（库里只保留 A，拿 B 的照片当陌生人查询）：相似度 **0.255 / 0.312 / 0.384**，全部低于阈值 → **3/3 正确拒识**。

阈值 0.6 的位置是安全的：正常本人 ≥ 0.69，陌生人 ≤ 0.49，中间有明显间隔。

### 6.3 已知边界（答辩时可以主动讲，比被问出来好）

1. **小人脸不可靠**：检测框 < 90px（全身照、远景合照）会被判为陌生人。演示请用**半身照或自拍**。
2. **远景 / 多人合照**：一张 1024×768 的五人合照里，人脸只有 26–36px，全部被拒；照片整体旋转时 MTCNN 检测也会失效。
3. **`resnet18` 只能做对照**：它满足作业「使用 ResNet18」的字面要求，但 ImageNet 通用预训练区分能力弱——实测类内 0.841、**类间也有 0.674**，超过 0.6 阈值，会把陌生人认成库里的人。**演示请用默认的 `inception_resnet_v1`。**
4. **换骨干必须重新注册**：两种骨干的特征空间不通用，代码会抛明确异常提示。

### 6.4 关于「5 点人脸对齐」的实测结论

项目实现了 ArcFace 标准的 5 点相似变换对齐（`face_detector._align_by_landmarks`），替代原来的「检测框 + 边距 + 双眼旋转」裁剪。

用同一人的 5 张真实照片做留一法对比：

| 裁剪方式 | 命中 | 最高分均值 |
| --- | --- | --- |
| 旧裁剪（box + 边距） | 4/5 | **0.7902** |
| 5 点相似变换对齐 | 4/5 | 0.7609 |

**对齐在数学实现上是正确的（变换方向、逆映射、退化保护都验证过），但在本数据集上没有带来识别率提升，均值反而低 0.03。** 项目如实保留了这段实现，也不把「提升」写进结论——负结果同样是结果。
